Frequently Asked Questions

What is VulkanMod?

You can think of VulkanMod as a voxel rendering engine built with Vulkan, which replaces Minecraft's OpenGL engine to improve performance. Therefore it's not a just a direct port of vanilla OpenGL engine.

What do I need to run this mod?

You will need a GPU with at least Vulkan 1.2 support to run this mod. To check if your GPU support Vulkan please run vulkaninfo in a terminal.

How can I fix "Vulkan Loader not found"?

The message means that your GPU doesn't support Vulkan. Make sure that your GPU drivers are up-to-date and that your GPU model actually supports Vulkan. If that's not the case you will need to use another GPU.

What launcher do I need?

Most launchers are fine, but we would generally recommend using a legit launcher instead of cheat, pirate or modded clients. Though we do provide support for third party clients if proper logs are given, we can't fix launcher issues.

Does this mod support shaders? (not the priority)

Not yet, We are working on them but there's still a long way to go. No ETA at this moment.

What about Linux and macOS?

You shouldn't encounter any issues with using VulkanMod on Linux, for help on how to install it on Linux, please check out the linux install guide. Native Wayland support has been added in 0.3.6, ensure you are running the latest update.

I still have issues, where can I get help?

For assistance, visit our issue tab. Include launcher, logs or crash reports, steps to reproduce and list of installed mods for a quick and effective problem solving.
